Exposed here · X1 Keys in red never leave the device in a deployment This page displays k_s^a, the blinding factor and the unblinding inverse so that a demonstration can be followed. In a production system those values are non-exportable: they exist only inside the operations that use them — signing and blinding — and no interface, log or file ever contains them. Nothing in red would be visible or savable on a real device.
Absent · A10 This client asks for a token one way; the iOS one asks two There is a second route in which the request is a document the citizen signs in their own wallet — the European Digital Identity Wallet, and in Hungary the DÁP application — which makes it a qualified electronic signature and a legally probative record. It is in the iOS application and not here. The reason is cost rather than capability: the office decides by rebuilding the document byte for byte, so every client that writes one needs its own implementation identical to the others, and a browser would be the third.

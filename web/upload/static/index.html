Hand in a signed token request

Your voting application wrote a document and you signed it in your wallet. This is where the signed document is given to the Registration Office. The office reads who you are from the certificate that signed it, checks that the document is a token request and nothing else, and — if you are on the electoral register and have not already been issued one — releases your token.

Then go back to the voting application and press Collect. The token is handed to whoever presents the blinded value, which only that application holds, so nothing you do here can collect it for you and nobody who takes this file from you can use it.



What the office is about to read

Picked up from the document in your browser, before anything is sent, so that you can see it is the request you meant to sign:

Those three should match what the voting application showed you. This page cannot check them for you: it is served by the office, and a check performed by the party being checked is not one. The office does the same reading again on its own side, from the bytes your signature covers.

Substituted · S6 What this demo substitutes An office may take its anchors two ways, and this page reports which this one did: from the European trusted list, which is signed and names every recognised authority with the dates it was granted — or from a certificate an operator pinned by hand, downloaded from the authority's own server and corroborated by nothing. Only the first lets an office say your signature is qualified; on the second it answers that it has no standing to judge, which is not the same as no. Either way the list is read from a dated snapshot and never fetched while a poll runs, so a service withdrawn since it was taken is still trusted here.
Absent · A2 What this build does not do Nothing anonymises this upload. The office sees the address it arrived from and the minute it arrived, and a ballot submitted from the same address shortly afterwards is linkable to it by timing alone. The cryptography does not leak the link; the network does.

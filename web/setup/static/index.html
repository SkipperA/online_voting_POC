Publication cadence

How often the box publishes the figures, in seconds. The close is always a publication point, so an interval longer than the poll means the close is the only one — which is what a small electorate wants, since what matters is how many voters stand behind each published number. Fixed once the ballot box is open: an interval is a promise about a running poll, so it has to be made before the poll runs.

Electoral register

Presence in the register is the whole of the eligibility statement. The office administers it and never populates it — here, enrolment also mints a wallet persona, which is the demo standing in for a citizen who already holds a qualified certificate.

    Mint a new election

    This is not an amendment Every key pair is replaced: the office's token key, the office's statement key, the box's statement key. Every token already issued stops verifying, every receipt stops being evidence, and the fingerprint a voter pinned stops being the fingerprint of the election they pinned it for. The ballot box and the released-token register are discarded with them. That is what a different election is — which is why this origin is one the poll runs without.

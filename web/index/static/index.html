Anonymous Authenticated Ballot System

A demonstration of the design in Proposal for a Secure, Private, and Coercion-Resistant Online Voting System. Eight origins, one process — for now.

This is a demonstration, not an election The voters are fictional and every key in this repository is published on purpose. Several parts of the design are substituted or absent here, and each is labelled where it occurs rather than only in a document. Read docs/Demo_Scope_Limits.md before drawing conclusions from a run.

Origins

A browser origin is scheme, host and port, so separate ports make these genuinely separate — separate script contexts, separate fetch policies, no shared cookies. Six are trust domains; the other two are not. Every page carries a band in its own colour saying which of these it is; the six colours group into three families, and the two that are not trust domains have no colour at all.

OriginServes

A run, in order

  1. Setup console — enrol voters. Phase A: what is authored before the poll opens. The poll runs with this origin stopped.
  2. Ballot box — open the poll. An act of an operator rather than a clock (E1): until it happens submissions are refused and nothing is recorded.
  3. Voter application — generates an ad-hoc key pair, blinds its public half, saves token-request.json.
  4. Wallet — load that file, check it against the configuration, consent. The wallet signs hash([id, c]) and transmits [id, c, s] to the office itself. Nothing comes back through the voting application.
  5. Voter application — collects the reply by presenting c, unblinds, verifies, marks a ballot and casts it.
  6. Checker — the checks of §3.7, from an origin the voting application does not control.
  7. Ballot box — close the poll. Every record is released in clear, accepted and rejected alike, and the checker's recount and its downloads become available.

Two surfaces are not steps in a run. The office's back office shows what the office records beside what it discloses; supervision shows the release register with the identifiers in it. Both exist to be read rather than driven, and a voter reaches neither.

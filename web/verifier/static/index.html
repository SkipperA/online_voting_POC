Cross-check a downloaded election

Load the three files and every check is run against them: the tokens, the vote signatures, the hash chain, supersession, the count audit and the tally.

This is the convenient check, not the strongest one This page is served by the same deployment that ran the election, so a verdict it returns is a verdict from the operator. It is here so the checks are easy to run and easy to watch. The check that does not rest on trusting anyone is the same program run on a machine none of these origins controls — it is downloadable below, and it needs Python and cryptography and nothing else.

The three files

Election_config_….json from the config origin
EBB_dump_….json from the ballot box, once closed
VRO_dump_….json from the office

—

All three download from the checker page. Each is checked as it is chosen, so a file in the wrong place is named rather than discovered halfway through. Note that VRO_supervision_….json is a different artefact — it names citizens, comes from the supervisor origin, and is not part of this check.

Run it yourself instead

The same program, to run where nobody involved in this election can reach it.

python verify_election.py Election_config_demo-2026.json EBB_dump_demo-2026.json VRO_dump_demo-2026.json

It imports nothing from this project — the standard library and cryptography. It exits non-zero if any check fails.
